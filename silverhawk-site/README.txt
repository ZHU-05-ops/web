SILVERHAWK 單頁樂團網站

本機預覽：
1. 將整個 silverhawk-site 資料夾保留完整結構。
2. 最簡單：直接用瀏覽器開啟 index.html。
3. 如果影片/音訊因瀏覽器安全限制無法播放，建議用 VS Code 的 Live Server，或在資料夾內執行：
   python -m http.server 5500
4. 再開啟：http://localhost:5500/

檔案結構：
- index.html
- assets/hero.webp
- assets/story.webp
- assets/closeup.webp
- assets/silverhawk-new-single.mp3
- video/silverhawk-live.mp4

網站已包含：
- 固定/置頂 Apple 風格導覽列
- 樂團故事
- 團員介紹
- 2026 巡演場次與倒數
- 可自行操作的音樂試聽播放器
- 現場演出影片
- RWD 手機版導覽與排版
